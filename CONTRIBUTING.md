# Contribuir

Abre una incidencia para describir el problema o la mejora. Si afecta a la cámara
o a los gestos, indica sistema operativo, navegador y pasos de reproducción.
Evita adjuntar grabaciones o información personal sin consentimiento.

Trabaja en una rama y envía una solicitud de cambios. Ejecuta `npm run format`,
`npm run lint`, `npm test` y `npm run build`. Documenta qué verificaste en un
navegador y con qué equipo.
