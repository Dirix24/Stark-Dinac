Control del escritorio con la mano

Cámara apagada
Izquierda Derecha

Puntero y selección
Mueve el índice de cualquiera de las manos. Junta pulgar e índice y suelta para hacer clic.
Doble clic y menú contextual
Pulgar y meñique para doble clic. Pulgar y anular para clic derecho.
Selección con dos manos
Con la otra mano, mantén pulgar y anular para Ctrl, o pulgar y meñique para Mayús. Haz clic con la mano del puntero.
Mover ventana
Apunta a la barra de título, mantén el pellizco o cierra el puño y desplaza la mano. Abre el puño para soltar.
Scroll con dos dedos
Coloca el puntero sobre el contenido. Extiende solo el índice y el dedo medio y apunta arriba, abajo o a un lado. Mantén el gesto para seguir desplazando.
Tamaño con una mano
Selecciona una ventana. Junta pulgar y dedo medio. Sube para ampliar o baja para reducir.
Ventana con dos manos
Pellizca con pulgar e índice en ambas manos. Muévelas juntas para desplazar la ventana. Sepáralas para ampliar o acércalas para reducir.
Pausa desde cualquier ventana con Ctrl + Mayús + F8.
